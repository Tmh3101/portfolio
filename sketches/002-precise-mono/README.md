## Variant 002 — Precise Mono

### Design stance
Strict black-and-white grid with monospace metadata, giving a tool-like, engineered
feel. References: Vercel / Cal.com (precision, hairline grids, no decoration).

### Key choices
- Layout: two-column hero (statement + mono spec list), strict 2-col work grid with
  hairline borders, experience as label/value rows.
- Typography: display for headings, mono for all metadata/labels.
- Color: monochrome only; "accent" is ink weight, not hue.
- Interaction: theme toggle + hover; no motion theater.

### Trade-offs
- Strong at: scannable, professional, "systems" personality.
- Weak at: slightly colder; less warm/editorial than 001.

### Best for
A technical audience (recruiters, engineers) who skim for stack and outcomes.
