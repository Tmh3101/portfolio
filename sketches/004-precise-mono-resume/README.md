## Variant 004 — Precise Mono + Resume (FINAL DIRECTION)

### Design stance
Variant 002 (Precise Mono) as the base — strict black-and-white grid, monospace metadata,
hairline separators — **plus a dedicated, scannable Resume section** so the page reads like a
résumé at a glance: experience as bordered `resume-row` entries (date column + role + one-line
scope), skills as an inline mono tag row, and a Download CV action.

### Key choices
- Hero: two-column (statement + mono spec list), same as 002.
- Work: strict 2-col hairline grid, same as 002.
- Resume: experience rows in a single bordered container (no floating cards); skills as a mono
  tag line; CV download button in the section header.
- Color: monochrome only. Accent = ink weight, not hue.
- Motion: theme toggle + hover only.

### Trade-offs
- Strong at: professional, precise, AND résumé-grade scannability in one page.
- Weak at: slightly denser than pure 002; needs care so the resume block doesn't dominate.

### Best for
The chosen direction — a recruiter or engineer who wants both the "product" feel and a fast
full-history read.
