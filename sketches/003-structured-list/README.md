## Variant 003 — Structured List

### Design stance
Information-dense list views replace every card grid. One row per item, mono metadata
aligned in columns. Optimized for scanning outcomes fast.

### Key choices
- Layout: compact hero, then work/experience/skills all as aligned list rows.
- Typography: mono carries the entire list; display only for hero + section eyebrows.
- Color: monochrome; density comes from rhythm, not boxes.
- Interaction: theme toggle + hover; nothing else.

### Trade-offs
- Strong at: maximum information per scroll, very "résumé/terminal" efficient.
- Weak at: least visual warmth; small screens need the grid to collapse gracefully.

### Best for
A hiring manager who wants the full picture in 10 seconds.
